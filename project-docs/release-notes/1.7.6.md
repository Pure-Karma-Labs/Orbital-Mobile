## What's New (draft copy)

### App Store (limit 4000 characters)

```
Easier-to-follow conversations
• Reply to any message with the new reply arrow.
• Replies stay grouped under the message they answer.
• Tap “Replying to @name” to jump to that reply. It's highlighted when you land on it.
• Collapse and expand long reply branches.
• Posts and replies show the exact date and time they were sent.

Posting and uploads
• If you leave a post or upload you haven't sent, you'll be asked before it's thrown away.
• Retrying a failed post reuses media that already uploaded, so you don't wait for it again.
• Cancelling a video while it's being prepared is more reliable.

Sign-up
• Clearer sign-up errors, shown right next to the field that needs fixing.
```

### Play Console (limit 500 characters)

```
• Reply to any message with the new reply arrow
• Replies stay grouped under the message they answer. Tap "Replying to @name" to jump to that reply
• Collapse and expand long reply branches
• Posts show the exact date and time they were sent
• You'll be asked before an unsent post or upload is thrown away
• Retrying a failed post reuses media that already uploaded
• Cancelling a video while it's being prepared is more reliable
• Clearer sign-up errors, shown next to the field that needs fixing
```

- **Deliberately not announced:**
  - #823 (#815, iOS 27 UIScene lifecycle). 1.7.5 was built on the iOS 26 SDK and already launches on iOS 27, so users see no change. Warm `orbital://` links now work on iOS, but deep links aren't a user-facing feature yet.
  - #825/#837/#744 (telemetry and Sentry scrubbing). Describing it would invite "what was sent before?"
  - #810/#801/#807/#809/#770 (build and dependency plumbing).

- **The image-sanitizer work in this release is deliberately not announced**
  (refs #732, #736). Three reasons, all decided with the owner on 2026-09-23:
  - **iOS is unaffected in practice.** The picker re-encodes to a 2048px JPEG
    and Live Photos arrive as stills, so there is no user-visible change to
    describe. Nothing else was ever verified on an iOS device — the evidence
    behind these changes comes from a Galaxy S24 and a Pixel.
  - **Android already has it.** The truncation shipped in 1.7.5 (version code
    21), live on Play — owner-confirmed 2026-09-23. Re-announcing it in 1.7.6
    would be wrong on that platform too.
  - **Copy that describes it reads as an admission.** Any phrasing along the
    lines of "photos now post without hidden location data" implies earlier
    builds shared it. Store copy must never imply that.
