# Orbital 1.7.6 — "What's New" draft

Working draft of the store release notes for 1.7.6. Items are appended here as
they land, so the copy pasted into App Store Connect / Play Console at
submission time is written once and reviewed once. See
`project-docs/store-listing.md` for the evergreen listing metadata.

**Rules for this file**

- Entries describe **shipped, user-visible behaviour only**. If a change is not
  in the build being submitted, it does not go here.
- Never name a security issue, describe its mechanism, or announce a fix that
  has not been deployed and released. Release notes are public the moment they
  are uploaded.
- Write in plain language, the way the person holding the phone would describe
  it — no marker names, no file formats, no internal terminology.
- Internal notes stay in the "Internal notes" section, limited to public issue
  numbers. Nothing from that section is ever uploaded.
- App Store copy must never mention Android or cross-platform availability
  (same rule as the listing metadata).
